# AI 时代个人数字素养基础课：从工具使用者到 AI 工作流设计师

> 课程 slug：`ai-digital-literacy`  
> 定位：面向「会用 AI 聊天但不知如何深度嵌入工作」的学员。国内工具优先、合规使用优先、实战落地优先。

---

## 一、课程定位与核心原则

**目标学员**：会用 AI 聊天但不知如何深度嵌入工作的学员  
**核心原则**：国内工具优先、合规使用优先、实战落地优先

> **关键认知前置**：国内 AI 生态在 2026 年已非常成熟，豆包、DeepSeek、Kimi 等对话工具，WorkBuddy、豆包工作、Trae Work 等 Agent 工具，配合飞书知识库，已足以支撑一整套小型 OPC（个人电商）的运转。不需要依赖国外工具也能跑通。

---

## 二、课程内容体系（6 讲）

### 第 1 讲：国内 AI 生态地图与工具选型
- 对话型：豆包、DeepSeek、Kimi、通义千问、文心一言的能力差异
- Agent 型：WorkBuddy、豆包工作、Trae Work——模型是大脑，Agent 是实习生
- 编程 IDE：CodeBuddy、Trae、通义灵码
- 客户端价值：多模型切换、历史管理、接入 API；长文档用 Kimi、代码用 DeepSeek
- 文件与知识管理：Markdown / CSV / JSON / PDF；飞书知识库、语雀、石墨
- 实操任务：做一份个人 AI 工具选型手册

### 第 2 讲：AI 辅助办公与知识管理
- 思维转变：从「先写再润色」到「用 AI 生成骨架，你来填血肉」
- 文档 / 表格 / 演示一站打通
- 用飞书知识库、语雀、石墨搭建 AI 可读取的知识库
- WorkBuddy + 飞书知识库即可管理小型个人电商的内容生产、客户回复、数据分析

### 第 3 讲：看懂技术架构：模型、API 与商业模式
- 软件是怎么做出来的：前端 / 后端 / 数据库 / 服务器
- 软件形态、部署方式、商业模式
- 常用术语：API / SDK / 插件
- 开源与闭源、SaaS 与本地部署

### 第 4 讲：模型能力边界与提示词进阶
- 大模型不是全知全能：概率接龙、上下文窗口、Token
- 进阶提示词 RTFC（角色 / 任务 / 背景 / 格式 / 约束）
- 思维链、Few-shot、系统提示词
- AI 幻觉识别三招：交叉验证、溯源检查、人工复核
- 高风险场景边界：医疗 / 法律 / 财务

### 第 5 讲：合规使用与数据安全
- 网络现实说清楚，国内工具已够用
- 数据安全与版权
- 隐私保护习惯

### 第 6 讲：跨客户端接入与 API 调用进阶
- API 是同一模型的标准入口
- 三类客户端：网页端 / 桌面客户端（ChatBox / LobeChat / NextChat）/ 集成工作台
- ChatBox 接入四步：自定义 API 兼容模式 → 填地址密钥 → 选模型 → 发「你好」验证
- 进阶认识 MCP：让模型从「只会聊」变成「能动手」
